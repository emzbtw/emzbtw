# emzbtw

I self-host my media stack and write small Go and Rust tools for it.

## Projects

- **[dotnix](https://github.com/emzbtw/dotnix)** single-machine NixOS flake: Umbriel/Noctalia Wayland desktop, sops-nix secrets, self-hosted media stack, just/nh rebuild workflow.
- **[vidicon](https://github.com/emzbtw/vidicon)** fast, keyboard-driven IPTV player for Linux: Xtream Codes live TV, guide, movies and series, played in mpv. Built with Rust and Slint.

## Stack

NixOS, Go, Rust, Jellyfin and the *arr stack, Tailscale.
